# MoviCol — Movilidad Inteligente

> Predicción inteligente de congestión para el transporte público de Bogotá usando Graph Neural Networks.

## 🚀 Características

- **7,444 nodos** — Estaciones y paraderos modelados como un grafo
- **GNN (GAT)** — Graph Attention Network que predice propagación de congestión
- **100% datos abiertos** — Todo proviene de datos.gov.co
- **Agente IA** — Consulta el grafo en lenguaje natural
